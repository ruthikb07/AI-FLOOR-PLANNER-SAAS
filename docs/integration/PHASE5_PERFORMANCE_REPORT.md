# Phase 5 performance report

Windows production browser verification uses Chromium with SwiftShader and the repository's established test budgets. The baseline desktop workflow reached the CAD preview and timed out waiting for the result. Its trace showed an active canonical validation request. The test now awaits the actual API receipt before checking the preview UI.

The next desktop run reached BIM selection, Precision CAD, Tower 3D and the selection highlight, then showed that Cutaway enabled section clipping while leaving the furniture layer hidden. A subsequent run reached working furniture visibility and night lighting and received a successful disk save response. It timed out before the success message was visible. The Studio now publishes the receipt status before refreshing its project list.

With the existing 300-second test budget, an isolated repeat timed out after a 191-second pointer move. Chromium logged pixel-readback stalls. Disabling trace screenshots removed that capture cost but still produced one timeout in two runs. The slower screenshot-free run spent 236 seconds in the orbit stage. DOM and network tracing remain enabled.

The software WebGL renderer now limits the drawing buffer to 500,000 pixels and reuses the directional shadow map during camera-only orbit. Scene changes, context restoration and exploded floor motion refresh shadows. The two isolated Windows production workflows completed in 52.8 and 43.6 seconds. The sampled orbit stages took 15.3 and 14.7 seconds, with at most one render per frame. The 792 × 630 drawing buffer used 114 draw calls, 89,274 triangles, 112 geometries and 10 textures during sampled orbit. Both trials downloaded a valid GLB, saved to disk and reloaded. SwiftShader was active. An Intel UHD Direct3D11 capability probe and two hardware-mode Studio replays were also executed.

The production WebGL suite also passed five real context losses and restorations on the updated renderer. Each restored a frame automatically, retained geometry and texture counts, and released the old context at the tested workspace or project transition.
