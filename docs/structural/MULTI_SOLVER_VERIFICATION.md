# Multi-solver verification

The recovered worktree uses Awatif 3.4.0 with PR #11 changes and a separately executed TypeScript Sparse-LU reference. PyNiteFEA 3.2.1 and Concrete Properties 0.8.0 run in a managed Python 3.12.13 worker. Numeric units, local roll, member releases and combination loads are mapped at the adapter. Every case carries actual executed solver diagnostics.

| Benchmark | Result and verification scope |
| --- | --- |
| Simply supported, fixed, cantilever and frame fixtures | Run the structural engine and Python tests for the supported combinations of reactions, end forces, internal stations, chord-relative deflection, stability and rotated/released members. Closed-form checks cover the explicitly modeled assumptions. |
| Rotated asymmetric 3D frame | Recovered Carbon 4 evidence recorded maximum displacement difference 7.37e−18 m and maximum moment difference 2.49e−13 kN·m for the compared paths. Actual backend selection matters because the rotated test can force the internal Sparse-LU reference. |
| Frozen 422-node / 744-element frame | Awatif C++ WASM, Sparse-LU and PyNite executed on identical inputs. The recorded PyNite–Awatif maximum translation difference was 1.0638e−9 mm. Both returned 62,281.423 kN vertical reaction and −5,588.952 kN Y base shear for the listed governing case. |
| Plate and second order | Direct Quad3D meshes at 2×2, 4×4 and 8×8 returned center deflections of 1.3295, 1.4204 and 1.4295 mm. The 8×8 result differs from the 1.4199 mm Kirchhoff reference by 0.678%. The isolated frame P-Delta fixture records amplification. PyNite rejects joined second-order frame and plate analysis. Canonical building shell analysis blocks pending valid mesh, edge support and slab load-transfer assembly. |
| CSI ETABS 23.3.2 | Prior native gravity data recorded maximum differences 1.04e−17 mm and 1.09e−11 N in the compared quantities. Native lateral/combined station differences reached 8.294 N axial, 7.224 N shear and 0.01819 kN·m bending. Support-face stations and section shear flexibility remain unresolved model differences. No new native equivalence claim follows from the frame replays. |
| Concrete Properties, historical COL_C23_L0 | Reproduces an inadequate 350 × 550 mm, 12-T28 section under the historical 4,674.35 kN and 264.21 kN·m weak-axis demand. Recovered worker evidence gives a sampled ray ratio of 5.396 and weak-axis ray capacity of 48.97 kN·m. The RH analytical 184.744 uses the historical clause interaction and a different axial-capacity curve. Both methods retain the rejection for the historical case. |
