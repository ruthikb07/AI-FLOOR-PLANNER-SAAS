## 1. Safety Boundary: Preliminary Model vs Final Structural Analysis

RH Planner enforces an architectural and structural firewall between **Preliminary Structural Geometry Generation** and **Certified Structural Engineering Analysis**.

Under Indian jurisprudence and international structural engineering standards (National Building Code of India 2016 Part 6 / Council of Architecture Guidelines / Municipal Corporation Building By-Laws):
- An AI software application cannot lawfully certify structural safety or calculate construction-ready rebar schedules without site-specific geotechnical parameters, micro-climatic wind velocity data, seismic acceleration spectra, and explicit signed engineering assumptions.

To prevent life-safety hazards and regulatory misrepresentation, the platform defines two discrete model states:

```
+-------------------------------------------------------------------------------+
|                       RH PLANNER STRUCTURAL WORKFLOW                          |
+-------------------------------------------------------------------------------+
|                                                                               |
|  [ Architectural Plan ]                                                       |
|           │                                                                   |
|           ▼                                                                   |
|  [ Preliminary Structural Project ]                                           |
|    - Levels, Grids, Columns, Beams, Slabs, Base Restraints                   |
|    - Review Status: ENGINEER_REVIEWED_MODEL_ONLY                              |
|    - Export Status: ALLOWED (Native CSI ETABS .EDB)                           |
|    - Stamp: "PRELIMINARY MODEL — NOT ANALYZED — FOR ENGINEER REVIEW"          |
|           │                                                                   |
|           ▼ (Structural Engineering Safety Gate)                              |
|  [ Missing Engineering Inputs Schedule ] ──► [ Geotechnical & Loading Data ]  |
|           │                                                                   |
|           ▼                                                                   |
|  [ Engineering Input Review & Signoff ]                                       |
|    - Review Status: ENGINEER_APPROVED_FOR_ANALYSIS                            |
|    - Reviewer: Licensed Structural Engineer (R.S.E. / S.E.)                   |
```

## 2. Missing Engineering Inputs Schedule

The preliminary model generated by RH Planner provides the geometry, framing layout, and boundary nodes. Before linear static, response spectrum, or non-linear pushover analysis can be executed for structural permitting or construction, the following inputs must be supplied by the project structural consultant:

### 2.1 Geotechnical & Foundation Parameters
| Parameter | Standard | Typical Residential Range | Required Consultant Input |
| :--- | :--- | :--- | :--- |
| **Safe Bearing Capacity ($q_a$)** | IS 6403:1981 | $150 - 300\text{ kN/m}^2$ | Borehole log soil test report |
| **Foundation Depth ($D_f$)** | IS 1904:1986 | $1.5\text{ m} - 3.0\text{ m}$ below ground | Site foundation recommendations |
| **Subsoil Classification** | IS 1893:2016 | Type I (Rock), II (Medium), III (Soft) | Standard Penetration Test ($N$-values) |
| **Water Table Elevation** | IS 6403:1981 | Seasonal maximum elevation | Hydrogeological report |
| **Foundation Type** | IS 2950 / IS 2911 | Isolated footings, raft, or piles | Structural consultant determination |

### 2.3 Lateral Wind Loading (IS 875 Part 3: 2015)
| Parameter | Symbol | Value Selection Criterion | Required Consultant Input |

## 3. Strict Enforcement of the Engineering Gate

The software implements algorithmic defenses against unverified structural execution:

1. **Synthetic SAFE/PASS Quarantine:**
   - Any synthetic or pseudo-analytical result claiming structural adequacy without verified finite-element execution is blocked.
   - The review gate rejects analysis exports lacking `engineeringInputs`.
   - The test suite `etabs-review-gate.test.ts` continuously verifies that uncertified submissions return `ENGINEERING_INPUTS_REQUIRED`.

2. **Visual & Metadata Marking:**
   - All exported `.edb` files and accompanying manifests include the explicit stamp:
     `PRELIMINARY MODEL — NOT ANALYZED — FOR STRUCTURAL ENGINEER REVIEW — NOT FOR CONSTRUCTION`
   - Review status is fixed to `ENGINEER_REVIEWED_MODEL_ONLY`.

3. **Headless ETABS Screenshot Limitation:**
   - CSI ETABS 23.3.2 OAPI does not expose image-rendering APIs in headless background STA processes (`cView` supports only `RefreshView` and `RefreshWindow`).
   - Rather than fabricating synthetic images, RH Planner honestly reports screenshot status as `NOT_VERIFIED`.
