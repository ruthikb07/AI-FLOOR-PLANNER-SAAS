# Building-wide analytical assembly

The automatic mesh request scopes plate and private node IDs by the supporting floor and region. It allocates private node indices after the saved frame-node array and carries the next free index across storeys. Saved frame identities are shared only when both proposals reference the same saved index. Adjacent coincident boundary vertices without that evidence retain different DOFs. Interfaces report matching frame DOFs, continuity review, or a nonconforming partition.

The Python geometry tests cover repeated region IDs on different storeys and adjacent decks with and without a shared beam. The synthetic two-storey gravity fixture automatically meshes both concentric decks against their supplied analytical topology. It uses one PyNite model with both slabs, eight beams and eight column lifts. Equal pressure on the two 16 m² plates delivers 64 kN total to the frame and 16 kN at each of the four symmetrical supports in about 100 ms of solver time. The worker rejects a coupled topology with any component disconnected from every support. This check is independent of the stiffness test.

Production assembly remains gated where matching beam edge IDs are absent or plate-to-beam offsets require constraints. Further work includes beam subdivision with physical ID, section, release, station and load preservation, explicit deck continuity across refined meshes, reviewed wall and stair connections, pressure-source mapping and building-scale solver result persistence. The current HTTP response is a geometry receipt. Its shared edges identify the existing frame connections that a later reviewed solver assembly can use.
