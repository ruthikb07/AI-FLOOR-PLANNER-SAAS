## Build and use

From the repository root, PowerShell:

```powershell
$dotnet = "$env:LOCALAPPDATA\RHPlanner\dotnet-sdk\dotnet.exe" # or your installed dotnet
& $dotnet build packages/backend/etabs-bridge/RHPlanner.EtabsBridge.csproj -c Release -p:EtabsInstallDir=D:\
```

Backend-only example (trusted deployment configuration, absolute local paths):

```ts
import { detectETABS, LocalETABSConnector, LocalETABSBridgeTransport } from '@ai-floor-planner/backend';
import type { ETABSCommand, StructuralAnalysis } from '@ai-floor-planner/core';

const detected = await detectETABS(); // registry discovery; optional explicit install directory
if (!detected.installations[0]) throw new Error('ETABS installation required');
const connector = new LocalETABSConnector(new LocalETABSBridgeTransport({
  bridgeExecutable: 'C:/your-repo/packages/backend/etabs-bridge/bin/Release/net8.0-windows/RHPlanner.EtabsBridge.exe',
  installDirectory: detected.installations[0].directory,
  modelDirectory: 'C:/RHPlannerModels',
  timeoutMs: 180000,
}));
async function checked(command: ETABSCommand) {
  const r = await connector.execute(command);
  if (!r.ok) throw new Error(JSON.stringify(r.error));
  return r.data;
}
await checked({ operation: 'connect' });
const fixture = (await checked({
  operation: 'fixture', sourceArchitecturalRevisionId: 'API-FIXTURE-ONLY-v1',
})).fixture!;
await checked({ operation: 'save', fileName: 'unique-test-frame.edb' });
await checked({ operation: 'analyze', caseNames: [fixture.caseName] });
const { result } = await checked({
  operation: 'results', caseName: fixture.caseName,
  frameNames: fixture.frameNames, nodeNames: fixture.nodeNames,
});
await checked({ operation: 'disconnect' }); // save first; no implicit discard
connector.close();
// type AnalysisBeam = StructuralAnalysis.StructuralBeam;
```

Production callers must handle failures with `try/finally` and choose whether to save or explicitly discard **their owned model**. The fixture test uses explicit discard only for its synthetic session.

Supported operations: `detect`, `connect`, `version`, `create`, `open`, `save`, `fixture`, `analyze`, `status`, `results`, `disconnect`. Every JSON-line request has `protocolVersion: 1` and a unique `id`; response IDs must match. `create/open/fixture` bind a source architectural revision. The host must invalidate/recreate that binding when project inputs change.

Connection states: DISCONNECTED / CONNECTED / FAULTED. Jobs: IDLE / RUNNING / SUCCEEDED / FAILED / UNKNOWN. Calls are serialized; concurrent calls receive BUSY. All checked OAPI return codes must be zero; failures preserve the API return code. Analysis success requires requested cases to report FINISHED, not merely a successful RunAnalysis call. Missing analysis results produce ANALYSIS_INCOMPLETE or NO_RESULTS.

## Local security and lifecycle

- Private stdin/stdout transport only: no HTTP, TCP listener, remote helper or generic method execution.
- Binary/install/model directories are trusted host configuration, never client-supplied command fields. No shell is used to launch the bridge.
- Model requests accept only .edb basenames within the configured directory; traversal, linked files/directories and overwriting a different existing model are rejected. Do not share this writable directory with untrusted processes.
- New application instance only; it is hidden after startup. No modification or shutdown of an existing user-owned ETABS session.
- Dirty models block replacement and normal disconnect. Explicit `discardUnsaved: true` is available for owned fixtures/recovery.
- Requests capped at 64 KiB, responses at 24 MiB. Timeout/transport loss reports UNKNOWN, kills only the bridge, and does **not** kill ETABS or retry a possibly completed mutation. EOF retains the native session. A retained hidden ETABS process may require manual recovery through CSI tools; inspect it before starting another job.
- No guarantee against external/manual modifications to the owned native model. General revision synchronization, cancellation and durable multi-job recovery are future work.
